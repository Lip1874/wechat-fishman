# 微信一键登录 + 数据权限方案

适配「钓友标点分享」小程序，基于微信小程序云开发 CloudBase。

## 1. 登录流程（静默鉴权，不强制弹窗）

```
首页 / 钓点地图          → 无需登录，游客可直接浏览全部钓点（微信审核要求）
点击【新增标点】/【我的】 → 触发微信一键登录（静默鉴权）
```

- **静默鉴权原理**：小程序调用云函数时，微信侧自动把当前用户 `OPENID` 注入到云函数的 `cloud.getWXContext().OPENID`。全程无需 `wx.login` 弹窗、无需 `wx.getUserProfile`，天然满足「静默鉴权、不强行弹窗」。
- **自动建档**：`loginService` 云函数以 openid 作为 `user` 集合的 `_id` 主键，登录时自动校验用户是否存在，不存在则自动创建（昵称/头像留空，后续在「我的」页完善）。
- **本地缓存**：`utils/login.js` 将 openid 缓存到本地 storage + `globalData`，避免重复调用云函数。

### 2.1 云函数 `loginService`（核心逻辑）

```js
// 登录（静默）：openid 主键校验 + 自动建档
async function login(OPENID) {
  const userColl = db.collection('user')
  let user = null
  let isNewUser = false
  try {
    const res = await userColl.doc(OPENID).get() // 以 openid 作为 _id 主键
    user = res.data
  } catch (err) {
    isNewUser = true // 文档不存在 => 首次登录
  }
  if (isNewUser) {
    await userColl.doc(OPENID).set({ data: { _id: OPENID, nickName: '', avatarUrl: '', createTime: db.serverDate(), updateTime: db.serverDate(), lastLoginTime: db.serverDate() } })
  } else {
    await userColl.doc(OPENID).update({ data: { lastLoginTime: db.serverDate(), updateTime: db.serverDate() } })
  }
  return { code: 0, openid: OPENID, isNewUser, user: {...} }
}
```

### 2.2 前端登录工具 `utils/login.js`

```js
const { ensureLogin, getOpenId } = require('../../utils/login')

// 页面中需要身份时才调用（Promise 风格）：
ensureLogin()
  .then(openid => { /* 已登录，继续操作 */ })
  .catch(err => { /* 登录失败，提示重试 */ })
```

导出 API：

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `getOpenId()` | `Promise<string>` | 获取 openid：内存缓存 → 本地缓存 → 云函数（并发去重） |
| `ensureLogin()` | `Promise<string>` | 一键登录入口，等价 `getOpenId()`，失败 reject |
| `getCachedUser()` | `Promise<object|null>` | 读取 user 集合当前用户资料 |
| `logout()` | `void` | 清除本地登录缓存 |

### 2.3 页面接入示例（首页【新增标点】）

```js
// miniprogram/pages/index/index.js
goAddPoint() {
  wx.showLoading({ title: '登录中', mask: false })
  ensureLogin()
    .then(() => {
      wx.hideLoading()
      const { mode, teamId } = this.data
      if (mode === 'team') {
        wx.navigateTo({ url: `/pages/addPoint/addPoint?mode=team&teamId=${teamId}` })
      } else {
        wx.navigateTo({ url: '/pages/addPoint/addPoint?mode=private' })
      }
    })
    .catch(err => {
      wx.hideLoading()
      wx.showToast({ title: (err && err.message) || '登录失败，请稍后重试', icon: 'none' })
    })
}
```

## 3. 数据库设计

### 3.1 `user` 用户集合

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | **openid（唯一主键）**，由 loginService 写入 |
| `nickName` | string | 昵称（「我的」页完善） |
| `avatarUrl` | string | 头像（云存储 fileID 或 URL） |
| `createTime` | Date | 首次建档时间 |
| `updateTime` | Date | 更新时间 |
| `lastLoginTime` | Date | 最近登录时间 |

> 说明：客户端 SDK 写入时系统会自动附加 `_openid` 字段，此处同时保留 `_id = openid` 双重索引能力；服务端按 `_id` 读写性能最优。

### 3.2 `fish_point` 钓点标点集合

每条数据由客户端创建时**自动携带 `_openid`**（标记创建人），核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `_openid` | string | 创建人 openid（系统自动注入） |
| `name` | string | 钓点名称 |
| `feeType` | string | 收费类型 |
| `waterType` | string | 水域类型 |
| `fish` | array | 目标鱼种 |
| `longitude` / `latitude` | number | 坐标 |
| `images` | array | 图片 fileID |
| `createTime` | Date | 创建时间 |

## 4. 数据库安全规则

### 4.1 `user` 集合 —— 仅用户本人可读写

规则级别：`PRIVATE`（私有）

```json
{
  "read": "doc._openid == auth.openid",
  "create": "auth.openid != null",
  "update": "doc._openid == auth.openid",
  "delete": "doc._openid == auth.openid"
}
```

> `PRIVATE` 级别即「仅创建者可读写」，与上述规则等价；集合数据主要由 `loginService`（云函数，天然绕过客户端权限）读写。

### 4.2 `fish_point` 集合 —— 所有用户可读，仅创建者可编辑/删除

规则级别：`CUSTOM`（自定义）

```json
{
  "read": true,
  "create": "auth.openid != null",
  "update": "doc._openid == auth.openid",
  "delete": "doc._openid == auth.openid"
}
```

> 规则验证：`read` 放通全部游客浏览；`create` 要求已登录（客户端创建时系统自动写入 `_openid`）；`update` / `delete` 要求操作者 openid 与文档 `_openid` 一致。

## 6. 与现有集合的关系（兼容说明）

| 现有集合 | 用途 | 与本方案关系 |
|----------|------|--------------|
| `user_profile` | 现有用户资料（昵称/头像/同步配置），由 `userService` 管理 | 保持不动，现有「我的/资料」页继续使用；`user` 为统一用户主表，可通过 openid 关联 |
| `dianpoints` | 现有钓点业务表（列表/详情/编辑走 `dianpointService`） | 保持不动；`fish_point` 作为标准化钓点表，安全规则已就绪，新业务可选用 |

> 业务写入统一走云函数（`userService` / `dianpointService`），云函数内使用 `cloud.getWXContext().OPENID` 做身份校验，不依赖客户端权限规则，因此两套集合并行无冲突。
